       - Note: the datetime('now') default must be parenthesized — DEFAULT 
         (datetime('now')) — a bare DEFAULT datetime('now') is a SQLite syntax
         error.
     - commit(), close(). Idempotent by construction (IF NOT EXISTS).

     1. Open a connection, SELECT COUNT(*) FROM users. If > 0, close and return

        - day 21 — Food — 8.25 — "Coffee and snacks"

     4. Insert each row via a parameterized INSERT INTO expenses (user_id, 
        amount, category, date, description) VALUES (?, ?, ?, ?, ?) — never
        string-format SQL.
     5. commit(), close().
